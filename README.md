# CollectionMechanicsInspector

Demonstrates ArrayList growth capacity, LinkedList overhead, and HashSet collision handling.

## Architectural Overview
This companion laboratory provides an authentic, runnable Java 21 implementation and automated JUnit 5 / AssertJ test suite.

## Running Tests Locally
```bash
mvn clean test
```


---

## Running the Interactive Demo Locally

Execute the Java 21 CLI application directly via Maven:
```bash
mvn compile exec:java
```

## Running the Automated Test Suite

Run the full JUnit 5 and AssertJ verification suite:
```bash
mvn test
```
